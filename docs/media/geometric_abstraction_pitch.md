# Editable geometric abstraction pitch figure

[Editable SVG](geometric_abstraction_pitch.svg) ·
[Vector PDF](geometric_abstraction_pitch.pdf) ·
[3920 × 1176 PNG](geometric_abstraction_pitch.png) ·

The compact 14 × 4.2 inch composition uses two aligned horizontal loops and
a small geometric-state example. Visual input is labeled without specifying a
sensor modality. Muted terracotta marks repeated image interpretation, teal
marks geometric input, and an amber dashed path highlights visual input on demand.
The bottom benefit strip is omitted.

The SVG retains live text and separate vector paths, shapes, and arrows. Open it
in a vector editor to edit labels or rearrange elements; use the Python source
for reproducible layout changes. Fonts are DejaVu Sans and DejaVu Sans Mono.
The PDF embeds fonts; the PNG is a presentation preview.

This conceptual pitch diagram contains no experimental measurements, global
heading, or results panel. All artwork is drawn with native vector primitives;
no generated bitmap is used.

Regenerate from the repository root:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python scripts/render_geometric_abstraction_pitch.py
```
